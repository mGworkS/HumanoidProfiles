# Lesbarer Steckbrief

Die generierte README eines Roboters beginnt mit Einordnung, Hersteller, Geltungsbereich und Tags. Darunter stehen Lebenszyklus, Größe, Gewicht, Nutzlast, Geschwindigkeit, Laufzeit, Batterie, IP Schutz, Autonomie und Entwicklerzugang. Kritische unbekannte Werte bleiben sichtbar.

Details zeigen Herkunft, Bedingungen, Softwarebezug und Nachweisstand. Angebote, offene Fragen und Ereignisse sind eigene Abschnitte. Die Daten werden nicht ein zweites Mal im Steckbrief gepflegt. Nicht erfasste Spezialmerkmale erzeugen keine leeren Tabellenzeilen.

Bei einer späteren Weboberfläche können Fachgruppen eingeklappt werden. Die Markdown Darstellung bleibt ohne spezielle Anwendung vollständig lesbar.

Offizielle Modellquelle und Screeningentscheidung stehen direkt vor den technischen Kennwerten. Der Quellenstand des Links bleibt sichtbar. Branchenansichten zeigen nur die aktuelle Auswahl im ersten Tabellenblock; andere Gruppen stehen in getrennten Abschnitten.
